\storystep{4}{The money: cheap to fix, if you know it broke}{leave_step4}
\begin{itemize}\setlength\itemsep{0pt}
\item \lab{priced, not executed} One long agent task (nebius-rebench-openhands, median 62 steps) sent whole to the cloud: USD 1.54 median, USD 2.63 p90 on claude-sonnet-5-5 at an assumed 70\% cache hit rate; USD 0.08 on claude-haiku-5-5\textsuperscript{9}
\item \lab{measured} Fixing a wrong answer in the cloud costs about USD 0.02 (mean USD 0.0201, median USD 0.0122); the cost is that the failure is silent.\textsuperscript{10}
\item Takeaway: escalating one wrong step is cheap; sending every long task to the cloud is not. The expensive part is not knowing which step went wrong.
\end{itemize}
