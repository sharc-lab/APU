## Harness (Task BB; all default off)
- `--stall-watchdog-s S` (launch_h1 -StallWatchdogS):
  - fires with outcome **stall** when the turn has had no streamer token and no
    new step for S seconds;
  - the record says `phase`: "prefill" (no token yet in the current step) or
    "decode";
  - with it, `--turn-watchdog-s T` fires with outcome **turn_budget_exceeded**.
- `--local-turn-limit 1`: the entry ends after turn 0 (stop_reason turn_limit).
- `--ctx-overflow-local-fail --context-window N`: under local_only, a step whose
  input + 512 exceeds N is not generated. The entry ends as a local fail
  (stop_reason ctx_overflow).
- `--step-log` adds a flushed post_generate line per step: wall, TTFT, generated
  tokens, ok/error, and the raw text with --debug-raw-text.
- `tools/repro_hang123.py run --chain-steps 4 --stall-s S --watchdog-s G`:
  - one base generate, then 4 generates on previous prompt + output + a pinned
    55-token suffix;
  - per-generate budget G; outputs recorded.

## Decision rules (fixed now; applied at closeout)
**Runner cells (X0, X1, X4), turn 0:**
- COMPLETED: a turn-0 telemetry row exists. It is also LOOP if stop_reason is
  max_steps (21 generates), or if 5 or more consecutive steps each generated
  exactly 512 tokens.
- STALL: the stall watchdog fired in phase "decode".
- PREFILL_OVER_STALL_LIMIT: the stall watchdog fired in phase "prefill".
  Reported with the step's prompt size; not counted as a stall.
- TURN_BUDGET_EXCEEDED_PROGRESSING: the budget fired. The steps and timing come
  from step_log.jsonl.
- ERROR / NOT_TESTED: as in P10.

**X1:** "cap converts the failure" if X1 ends turn 0 with ctx_overflow, and with
no stall and no budget fire.

**X2 / X3r (repro chains):**
- STALL: decode-phase stall.
- PREFILL_OVER_STALL_LIMIT: prefill-phase stall.
- ERROR: the generate raised.
- LOOP: all 5 generates completed and at least 4 generated 512 tokens.
- OK: otherwise.

**Classification:**
- "context-overrun regime": at least one X2 cell with N > 40,960 is STALL or
  LOOP with no error, and neither X2 cell with N <= 40,960 is.
- "input-specific": no X2 cell with N > 40,960 is STALL or LOOP, while X0 (the
  real input on the runner path) is STALL, LOOP or TURN_BUDGET_EXCEEDED_PROGRESSING.
- "not length-specific": an N <= 40,960 cell is also STALL or LOOP.
- "neither": X0 completes without LOOP and no X2 cell is STALL or LOOP.
- PREFILL_OVER_STALL_LIMIT counts toward no class.

**X4:** "knob changes the outcome" if X4-C2 or X4-C3 gets a different X0 class.

**XPS vs T2S:** X0's class on each host is reported side by side once X0-XPS runs.
Not a device claim from one run each.
