## 2026-07-22 — Budget-Constrained Policy Sweep (Evaluation Layer)

### Sweep configuration

- Task suite: 14 tasks from `harness.adapters.sdk_direct.TASKS`
- Policies: `all_cloud`, `all_local`, `static_category`
- Seeds: 5 (`0..4`)
- Budget levels: 0%, 10%, 25%, 50%, 100% of per-seed `all_cloud` baseline cloud-token spend
- Backends:
  - Cloud: OpenAI `gpt-4o-mini`
  - Local: Ollama (default `qwen2.5:1.5b`, configurable)
- Replay: all generation and judge calls routed through ReplayCache (`APU_REPLAY_MODE`)

### Outputs

- Sweep artifact: `results/pareto_results.json`
- Pareto plot/table: generated by `analysis/pareto.py`
- Speculative report fields (when `speculative` policy is enabled):
  - agreement rate per category
  - rollback cost (cloud tokens + rollback latency)
  - latency percentiles with speculation on vs off
- Router-training log fields per decision:
  - `step_index`
  - `step_type`
  - `category`
  - `backend_chosen`
  - `remaining_budget`
  - `local_output_hash`
  - `cloud_output_hash` (if both ran)

### Notes

- Deterministic task scoring is programmatic where applicable.
- Open-ended scoring uses an LLM judge (`gpt-4o-mini`) with versioned prompts under `evaluation/judge_prompts/`.
